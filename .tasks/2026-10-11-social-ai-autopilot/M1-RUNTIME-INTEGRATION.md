## Stage contract

1. Preparing: confirm actual numeric owner, Deadlock category and Twitch source; choose only authorized canonical source files; inspect bounded media; retain a source identity and the selected layout/config/skill snapshots. Missing or changed source becomes a visible failure, not another paid analysis.
2. Transcribing: use the transient owned local STT helper and the approved packaged server/model-directory snapshot. Persist actual text and timed segments, with optional detected language. No-speech is an empty real result, not a failure or invented subtitles. Stop/reap the owned process on all paths. User-home smoke proof is not hardened production proof.
3. Analyzing: load only Deadlock-understanding/highlight skills, extracted timestamped native image blocks, measured source metadata, bounded transcript and any demonstrably relevant read-only Brain evidence. Use strict structured analysis with observed timestamps, concise explanations and explicit uncertainty. Sparse frames are not proof of complete temporal gameplay understanding.
4. Planning: reuse the persisted analysis. Load editing/layout/copywriting skills only here, with current C1 publication language and existing templates. Produce bounded structured `EditPlan` plus publication metadata where supported. Deterministically validate intervals, actual source duration, retention/continuity and subtitle overlap before FFmpeg. Never accept arbitrary FFmpeg filters, paths, tools or shell commands from the model.
5. Rendering: revalidate source identity; load the existing stable layout; rebase real speech cues and flag omitted partial cues; retain source audio content. Render one output. Default-off multi-output/experimental preferences do not justify silently adding extra renders. Record FFmpeg duration separately from provider latency/cost.
6. Validating: pipeline-owned integrity/decode/resolution/aspect/audio/duration/subtitle/framing/continuity checks. Quality concerns become review reasons. Use only C2 to create/complete an AI produced version, with manual job metadata and null C3 job_id. Finish the manual job only after the C2 review file and association are durable. No approval, scheduling or publication in M1.
