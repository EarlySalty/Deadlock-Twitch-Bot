# B9 Infra-Schema-Audit

Scope: Read-only Python->Rust parity audit for the infrastructure domain: Storage/DB schema, crypto, config/runtime settings, LLM providers, HTTP-core behavior, domain value objects and knowledge. Baseline intent ledger was applied from `rust/docs/audit/2026-06-27/00-baseline.md:40-60`: SQLx migrations replace `ensure_schema`, one-shot Python migrations may be deliberately dropped, AES interop or reauth is accepted, OpenAI is intentionally removed, and `manual_verified` legacy fallback is intentionally removed. No secrets were read and no git commands were used.

Verdict: vollständige Portierung ist widerlegt. The highest-risk drift is not booleans-as-int on partner flags, but legacy analytics table types still present in `rust/migrations/20260601000000_baseline_schema.sql` without corrective migrations for all columns.

## Summary

- Gesamt: 29 Befunde.
- Klassifikation: parity 17, deliberate 4, missing 3, bug 5, regression 0.
- Kritisch zuerst: 4x P1 schema/data bugs in session/chat analytics tables, 1x P2 DB config bug.
- Keine validierte P0.
