# Doku zu diesem Repo

User-facing Doku zu Features dieses Bots liegt zentral im Master-Bot-Repo unter `Deadlock-Bots/docs/twitch-streamer-dashboard.md` und `Deadlock-Bots/docs/twitch-clips-und-social.md`. Sie wird vom FAQ-Bot indiziert.

Admin-, Ops- und Deployment-Doku liegt hier lokal unter `docs/internal/`. Bestehende Doku unter `docs/streamer/`, `docs/ops/`, `docs/features/` wird schrittweise nach `docs/internal/` migriert.

**Code-/Architektur-Doku:** Die funktionsgenaue Architektur je Subsystem (was jedes Modul tut, welche Klassen/Funktionen es hat, Datenfluss, Stolperfallen) liegt unter [`docs/architecture/`](architecture/README.md) — die Tiefen-Schicht zu den Überblicks-Dokumenten `ARCHITECTURE.md`, `MODULES.md`, `DATABASE.md`, `API.md`.
